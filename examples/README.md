# Examples

This folder contains sample source files for different languages. Open them in Neovim with grandline active to preview how Treesitter highlights each filetype:

```sh
nvim examples/react/App.jsx
nvim examples/ruby/sample.rb
```

These are intentionally varied to cover a wide range of syntax elements — functions, types, strings, comments, JSX/ERB tags, etc. — so you can visually verify highlight groups across languages when making palette or highlight changes.
