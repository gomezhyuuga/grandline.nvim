# snacks.nvim Picker Highlight Groups

This document lists all highlight groups supported for the snacks.nvim picker plugin.

## Categories and Groups

### Main Window

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerNormal` | Main picker window background and text |
| `SnacksPickerBorder` | Picker window border |
| `SnacksPickerTitle` | Picker window title |
| `SnacksPickerFooter` | Picker window footer |

### Input/Prompt Area

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerInput` | Input field background and text |
| `SnacksPickerInputBorder` | Input field border |
| `SnacksPickerInputTitle` | Input field title/label |
| `SnacksPickerInputIcon` | Icon in the input area |

### Results List

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerList` | Results list background |
| `SnacksPickerCursor` | Current cursor position |
| `SnacksPickerCursorLine` | Current line highlight |

### Preview Window

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerPreview` | Preview window background and text |
| `SnacksPickerPreviewBorder` | Preview window border |
| `SnacksPickerPreviewTitle` | Preview window title |

### Matching Highlights

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerMatch` | Exact match highlight (bold) |
| `SnacksPickerFuzzyMatch` | Fuzzy match highlight |

### Files and Directories

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerDir` | Directory names |
| `SnacksPickerFile` | File names |
| `SnacksPickerIcon` | Generic file icons |
| `SnacksPickerIconDir` | Directory icons |

### Status Indicators

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerInfo` | Info messages |
| `SnacksPickerHint` | Hint messages |
| `SnacksPickerCount` | Item count display |
| `SnacksPickerSelected` | Selected item indicator |
| `SnacksPickerMarked` | Marked item indicator |

### Git Integration

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerGitAdd` | Added files |
| `SnacksPickerGitChange` | Modified files |
| `SnacksPickerGitDelete` | Deleted files |
| `SnacksPickerGitUntracked` | Untracked files |

### Diagnostic Indicators

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerDiagnosticError` | Error diagnostics |
| `SnacksPickerDiagnosticWarn` | Warning diagnostics |
| `SnacksPickerDiagnosticInfo` | Info diagnostics |
| `SnacksPickerDiagnosticHint` | Hint diagnostics |

### LSP and Symbols

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerLspKind` | Default LSP kind |
| `SnacksPickerLspKindFunction` | Function symbols |
| `SnacksPickerLspKindMethod` | Method symbols |
| `SnacksPickerLspKindClass` | Class symbols |
| `SnacksPickerLspKindInterface` | Interface symbols |
| `SnacksPickerLspKindModule` | Module symbols |
| `SnacksPickerLspKindVariable` | Variable symbols |
| `SnacksPickerLspKindConstant` | Constant symbols |
| `SnacksPickerLspKindProperty` | Property symbols |

### Special Picker Types

| Highlight Group | Description |
|-----------------|-------------|
| `SnacksPickerHelp` | Help text |
| `SnacksPickerKey` | Key bindings |
| `SnacksPickerValue` | Values |
