Legibility at size

At 16px one em is sixteen device pixels, so the 1024-unit grid maps at 64 units per pixel. Every stroke, gap and counter in this set is at least 80 units — about 1.25px — which is the floor below which a feature vanishes at 16px and mushes at 32px. The finest feature in the set is the 80-unit bridge between the skull's eye sockets.
