The set

Each glyph is one solid path on a 1024×1024 grid, so the terminal or the highlight group supplies the colour. Counters — the hatband, the eye sockets, the compass face — are reverse-wound subpaths rather than white shapes, which is what lets FontForge import them as real holes.
