# Icon design sources

The showcase board for the Grandline Icons font. Each `.dc.html` file is one
artboard.

| File | Board | Source |
|------|-------|--------|
| `Main.dc.html` | All eight glyphs with name, codepoint and use | generated by `gen-boards.mjs` |
| `Sizes.dc.html` | The 16/20/24/32/48px ramp, and 16px + 32px on every background | generated by `gen-boards.mjs` |
| `Contrast.dc.html` | Measured WCAG ratios per palette colour, and the safe tints | generated by `gen-context.mjs` |
| `InContext.dc.html` | Tabline, statusline, picker and LSP rows at real 16px | generated by `gen-context.mjs` |
| `canvas.json` | Board positions and sizes | hand-written |

Unlike the palette boards in `../`, these generators read the real geometry
out of `fonts/icons/*.svg` at build time, so the boards cannot drift from the
glyphs. The contrast numbers in `gen-context.mjs` are transcribed and must be
recomputed if the palette changes.

## Regenerating the boards

```sh
node docs/design/icons/gen-boards.mjs
node docs/design/icons/gen-context.mjs
```

`gen-context.mjs` imports the shared helpers from `gen-boards.mjs`, so running
it also rewrites `Main.dc.html` and `Sizes.dc.html`.

The boards pull Bebas Neue, Space Grotesk and JetBrains Mono from Google
Fonts; without network access the render falls back to local faces and the
type will not match.
