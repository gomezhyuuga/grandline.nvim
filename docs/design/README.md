# Design sources

The artboards behind `docs/images/grandline-palette.png` and the visual
reference sheet for the theme. Each `.dc.html` file is one board:

| File | Board | Source |
|------|-------|--------|
| `Main.dc.html` | All 29 palette colors with hex, RGB and inspiration | generated by `gen-main.mjs` |
| `Semantic.dc.html` | The 42 `palette.semantic` roles and where each color lands | generated by `gen-semantic.mjs` |
| `Statusline.dc.html` | The lualine bar in all six modes | generated by `gen-statusline.mjs` |
| `Editor.dc.html` | A syntax-highlighted buffer, tabline, statusline and diagnostics | hand-written |
| `canvas.json` | Board positions and sizes | hand-written |

The color values in the generators are transcribed from
`lua/grandline/palette.lua`, `lua/grandline/highlights.lua` and
`lua/lualine/themes/grandline.lua`. **When the palette or the highlight
groups change, update the generators to match** — nothing reads the Lua
at build time.

## Regenerating the boards

```sh
cd docs/design
node gen-main.mjs
node gen-semantic.mjs
node gen-statusline.mjs
```

## Regenerating the README image

Renders `Main.dc.html` at 2x and writes `docs/images/grandline-palette.png`.
Needs Chrome and ImageMagick.

```sh
cd docs/design
node to-standalone.mjs Main.dc.html /tmp/palette.html
google-chrome --headless=new --disable-gpu --hide-scrollbars \
  --virtual-time-budget=15000 --force-device-scale-factor=2 \
  --window-size=1000,2070 --screenshot=/tmp/palette-raw.png \
  "file:///tmp/palette.html"
magick /tmp/palette-raw.png -strip -define png:compression-level=9 \
  ../images/grandline-palette.png
```

The boards pull Bebas Neue, Space Grotesk and JetBrains Mono from Google
Fonts; without network access the render falls back to local faces and the
type will not match.
